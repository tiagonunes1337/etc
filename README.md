# Escola Técnica de Ceilândia - Projeto Web (2023)

Este projeto representa um marco significativo no percurso educacional e profissional, sendo desenvolvido em 2023 durante o curso de programação na Escola Técnica de Ceilândia (ETC). Ele reflete o aprendizado e a aplicação prática de conceitos fundamentais de desenvolvimento web.

## Descrição do Projeto

O site é uma representação digital da Escola Técnica de Ceilândia, com o objetivo de apresentar a instituição, suas instalações e informações úteis para a comunidade. Ele inclui:

*   **Página Principal (`site.html`)**: Apresenta a escola com um carrossel de vídeos e imagens, além de seções interativas com informações sobre o pátio, biblioteca e a própria escola.
*   **Página de Sugestões (`sugestões.html`)**: Um formulário simples para coletar feedback ou sugestões dos visitantes.
*   **Página de Localização e Contato (`locacont.html`)**: Informações sobre a localização da escola (com um mapa incorporado do Google Maps) e detalhes de contato da secretaria.

## Tecnologias Utilizadas

O projeto foi construído utilizando as seguintes tecnologias:

*   **HTML5**: Para a estruturação do conteúdo web.
*   **CSS3**: Para a estilização e design visual, com arquivos `index.css` e `index2.css` para diferentes seções.
*   **Bootstrap 4.1.3**: Framework CSS para um design responsivo e componentes pré-estilizados, como o carrossel e o acordeão.
*   **JavaScript (via Bootstrap e jQuery)**: Para funcionalidades interativas, como o carrossel de vídeos e o colapso de seções.

## Como Visualizar

Para visualizar o site, basta abrir o arquivo `site.html` em qualquer navegador web moderno. Certifique-se de que todos os arquivos (HTML, CSS, imagens e vídeos) estejam na mesma estrutura de diretórios para que o site seja carregado corretamente.

## Recursos Visuais

O projeto incorpora diversos recursos visuais para enriquecer a experiência do usuário:

*   **Vídeos**: `entrada.MOV`, `biblioteca.MOV`, `patio.MOV` são utilizados no carrossel da página principal para mostrar diferentes ambientes da escola.
*   **Imagens**: `biblioteca.jpg`, `escola.jpg`, `etc.png`, `quadro.jpg` complementam as informações visuais em várias seções do site.
